# Require MAVSDK library

## On Linux:
1. wget https://github.com/mavlink/MAVSDK/releases/download/v3.0.0/libmavsdk-dev_3.0.0_ubuntu22.04_amd64.deb
2. sudo dpkg -i libmavsdk-dev_3.0.0_ubuntu22.04_amd64.deb

# Matlab Interface
The GCS include a matlab passthrough (--matlab=[ip]:[port]) to run an external controller. The controller frequency is given
by the GCS and can be set using --hlc-freq=[freq]. Matlab should execute a control loop on reception of new data and send back
a command.

* Matlab should receive and decode the following struct (all float except last 3 are double):

```Matlab
struct( ...
'airspeedMeterSecond', [], ...
'northMeter', [], ...
'eastMeter', [], ...
'downMeter', [], ...
'northMeterSecond', [], ...
'eastMeterSecond', [], ...
'downMeterSecond', [], ...
'rollDegree', [], ...
'pitchDegree', [], ...
'yawDegree', [], ...
'altitudeAmslMeter', [], ...
'latitudeDegree', [], ...
'longitudeDegree', [] ...
);
```

* And encode and send the following struct (all float):

```Matlab
struct( ...
'sysId', single(0), ...
'rollCommand', single(0), ...
'pitchCommand', single(0), ...
'yawCommand', single(0), ...
'thrustCommand', single(0) ...
);
```
