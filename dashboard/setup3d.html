ABOUT THIS VIEW

This page is for pre-flight setup verification, not flight tracking: confirming the navigation origin is where you expect, and that each vehicle's reference trajectory is oriented and shaped correctly before launch. It loads the origin once from GET /api/origin and each vehicle's reference path once from GET /api/trajectory — both static reads, no WebSocket, since none of this needs to update at flight telemetry rates. Switching "Ground layer" to cached map tiles reads PNGs from a local tiles/ folder (the output of precache_field_tiles.py) and positions each one by converting its corners into the same local NED frame as the trajectories, using the origin above.
